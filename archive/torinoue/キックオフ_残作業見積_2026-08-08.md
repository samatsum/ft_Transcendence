## 5. ゲートと暦日（1日 4h）

### ゲート2（ログイン → ロビー → 試合 → ロビー復帰）

依存の骨格:

```text
W-02 → W-03 → W-04 → W-05 → W-08本結合
                              ↓
              F-04（先行可）→ F-03 → F-05 → F-08
```

| 見方 | 目安 |
|---|---|
| Auth クリティカル（W-02〜05 + 結合） | 約 38人時 → 約 **10 稼働日** |
| FE ゲート2（F-03 / F-05 / F-08） | 約 28人時。Auth 後半と並行し、**+約 5〜7 稼働日** |
| 手渡し・レビュー待ち | **+約 3〜5 稼働日** |
| **ゲート2 の暦** | **約 2.5〜3.5 週** |

### 全体（ゲート3 + W-15 + 仕上げ）

| 見方 | 目安 |
|---|---|
| 合計 | 約 **200人時** |
| 4人平均 | 約 **50人時 / 人** → 約 **12.5 稼働日 / 人** |
