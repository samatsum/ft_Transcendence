## 1. samatsum の役割

samatsum は **対人戦の心臓**（`sim.wasm` を Node 上で権威実行するレーン）かつ **テクニカルリード**。  
WS プロトコル（[02_設計書/2-WSプロトコル設計.md](../02_設計書/2-WSプロトコル設計.md)）の所有者。C エンジンとデモの実装元。

| samatsum が所有する | 他者に渡す／触らせない線 |
|---|---|
| W-10 GameRoom、W-11 ゲーム WS、W-08/W-09 ロビー系サーバ、W-12、W-14（maps・契約レビューは torinoue） | REST 形・Cookie 実装の最終形（torinoue） |
| snapshot JSON 形の提示（hminemur との最重要同期） | FE の画面コンポーネント実装（mamiyaza / hminemur） |
| アーキテクチャと重要境界の技術決定 | 日程・ブロッカー可視化の運用（torinoue = PM） |
| C（`codes/`）変更の相談窓口 | 原則、他3人が C を直さない |

Engine / Gameplay（E・G）は完了。残作業の本丸は **W-10 以降の TypeScript ゲームサーバー**。
