## 1. このドキュメントの目的

mamiyaza 担当分野の**残作業**（2026-07-30 時点）を F 単位に分解し、**60分スロット**で総量を見積もる。

- 1日あたりの稼働時間は考慮しない
- 他メンバー・API 待ちは度外視
- [torinoue_W作業見積もり.md](./torinoue_W作業見積もり.md) と同前提（初見・バッファ込み）

```text
F-01 → F-02 → F-03 → F-05 → F-04 → F-09 → F-10 → F-11 → W-16 → F-12 → H-01
```
