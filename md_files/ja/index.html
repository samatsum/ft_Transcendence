読む順

まず何を読むか

個人別 reading guide は廃止したため、以下の順に読めば全体像がつかめます。

  1. Git運用フロー.html 何かコミットする前に。branch → PR → CI → GitHub上でマージ → ローカルpull、というこのリポジトリの唯一の正しい統合手順。
  2. オンボーディング.html 役割・略号・モジュール境界・ゲート2の定義・FAQ。全体の共通知識。
  3. サーバー開発工程.html W-01〜W-16、エンジンをオンライン製品にする16工程の現在地・依存関係・コード入口を1枚で。
  4. explanations/エンジン構成.html エンジン構成。pf_* 境界・言語配置・ディレクトリ構成・app/web層の関係。
  5. explanations/サーバ権威モデル.html サーバ権威モデル。スナップショット補間と戦闘員（人/NPC）統合。オンライン対戦の芯。
  6. explanations/ビルドと実行.html ビルドと実行。3つのビルドターゲット・ループ反転・WASM入門。
  7. explanations/cubマップ書式.html .cub マップ書式。マップ文字・RSP/FPS判定・対戦マップのホワイトリスト。
