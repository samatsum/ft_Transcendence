## 7. 時間換算

| 指標 | 値 |
|---|---|
| **総スロット数** | **161** |
| **総作業時間（見込み）** | **161 時間** |
| 4人が完全並行（理論上） | 最長レーン **64h（torinoue）** が壁 |
| 1人あたり平均 | 40.25h |
| 全員 1日 4h のみ本 PJ | 約 **40 営業日**（4人合算 161h ÷ 16h/日） |
| 全員 1日 8h のみ本 PJ | 約 **20 営業日** |

> **161h は「4人の工数の和」**であり、1人が161時間働く意味ではない。並行度によりカレンダー日数は短縮される。
