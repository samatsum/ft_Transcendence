01 · Tooling

道具立て

用語意味
TypeScriptJavaScriptに型（変数の種類のチェック）を足した言語。ブラウザは実行できないので、必ずビルドでJavaScriptに変換してから配る
React画面を「部品（コンポーネント）の組み合わせ」として作るためのライブラリ。このプロジェクトの画面はすべてReactで書かれている
ViteTypeScript/ReactのコードをJavaScriptへ変換し、開発中はブラウザへ即座に反映してくれるビルドツール
Tailwind CSSあらかじめ用意されたクラス名（text-smやflexなど）をHTMLに直接並べて見た目を作る手法。別ファイルにCSSを書く量を減らせる
SPA（Single Page Application）ページ遷移のたびにサーバーから新しいHTMLを取得するのではなく、1枚のHTMLの中でJavaScriptが画面を書き換え続ける方式。/lobbyや/game/:idのようなURLの切り替えもJS側（ルーター）が担う

02 · React basics

Reactの基本語彙

用語意味
コンポーネント画面の部品を表す関数（例:ScoreBar・Button）。組み合わせて画面全体を作る
JSXTypeScriptの中にHTMLのようなタグを直接書ける記法。<div>{score}</div>のように書く
propsコンポーネントに渡す引数。C関数の引数と同じ発想
state（状態）コンポーネントが内部で持つ、変化する値。変わると画面が自動で再描画される
Hook（フック）useで始まる特別な関数。useState（状態を持つ）・useEffect（副作用を実行する）などReactの標準機能と、プロジェクト独自のuseLobbySocket・useGameSocketのような「カスタムフック」がある
Contextprops を各階層に渡さなくても、遠くのコンポーネントへ値を届ける仕組み。AuthContext（ログイン状態）などで使う
ルーター（React Router）URL（/lobbyなど）と表示するコンポーネントを対応付ける仕組み
route guardログインしていないユーザーを保護されたページから/loginへ弾く仕組み

03 · Data flow

サーバーとのやり取り

用語意味
fetch wrapperREST APIを呼ぶ処理を1か所にまとめた関数（apiFetch）。エラー形式の統一やトークン付与を毎回書かなくて済む
Toast画面の隅に一瞬出る通知（エラーメッセージなど）
ErrorBoundaryコンポーネント内で例外が起きても、画面全体が真っ白にならないようにする仕組み。評価要件の「コンソールにエラーを出さない」対策の一部
401リダイレクトAPIが「未ログイン」を返したら、自動的に/loginへ飛ばす処理

04 · GameView

対戦画面（GameView）まわり — EngineレーンやWレーンとの接点

用語意味
CanvasHTMLの中で絵を描ける領域。render.wasmが計算したピクセルをここに転送する
useGameSocketゲーム用WebSocketへの接続・自動再接続を管理するカスタムフック
補間（interpolation）サーバーから届く間引かれたsnapshot同士の「あいだ」を計算で滑らかに埋める処理。詳しくはサーバ権威モデル.html
HUDスコア・カウントダウン・接続状態など、3D画面の上に重ねて表示する情報レイヤー

render.wasmそのもの（Cのエンジン）はE-専門用語.html、 それを送り出すサーバー側はW-専門用語.htmlを参照。
