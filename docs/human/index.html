読む順

まず何を読むか

個人別 reading guide は廃止したため、以下の順に読めば全体像がつかめます。

  1. はじめに/プロジェクト概要.html ルートREADME.mdの日本語サマリー。今何が動いて何が動かないか、チーム、アーキテクチャ図。
  2. 専門用語/全体-専門用語.html この先の全ページで前提にする共通語彙（リポジトリ構成・サーバ権威・WS/REST・Git用語・42評価用語）。ここから読み始めるのが一番迷わない。
  3. 運用/Git運用フロー.html 何かコミットする前に。branch → PR → CI → GitHub上でマージ → ローカルpull、というこのリポジトリの唯一の正しい統合手順。
  4. 運用/ドキュメント作法.html docs/配下に何か書く前に。ページテンプレート・共通CSS・Mermaidの使い所・リンク切れの確認方法。
  5. はじめに/オンボーディング.html 役割・略号・モジュール境界・ゲート2の定義・FAQ。全体の共通知識。
  6. 開発状況/サーバー開発工程.html B系・I系、エンジンをオンライン製品にする16工程の現在地・依存関係・コード入口を1枚で。
  7. 開発状況/フロントエンド開発工程.html F系・GV系、動くサーバーをプレイヤーが触れる画面にする12工程の現在地・依存関係・コード入口を1枚で。
  8. 説明用/エンジン構成.html エンジン構成。pf_* 境界・言語配置・ディレクトリ構成・app/web層の関係。
  9. 説明用/サーバ権威モデル.html サーバ権威モデル。スナップショット補間と戦闘員（人/NPC）統合。オンライン対戦の芯。
  10. 説明用/ビルドと実行.html ビルドと実行。3つのビルドターゲット・ループ反転・WASM入門。
  11. 説明用/cubマップ書式.html .cub マップ書式。マップ文字・RSP/FPS判定・対戦マップのホワイトリスト。
  12. 説明用/テクニカルリード自己確認.html コードのどこで何をしているかをQ&A形式・file:line付きで即答できるようにする自己確認シート。archive/説明用/から新規移設。
  13. 評価対応/42モジュール対応表.html 42評価の各モジュール・必須要件が今どこまで実装済みか、コード入口とあわせて一枚で。評価当日の直前に開く用。
