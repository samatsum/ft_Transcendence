02 — Required Roles

管理役割の定義（課題書 II.1.1）

課題書 II.1.1 は PO / PM・スクラムマスター / テクニカルリード / 開発者（全員）の割当を義務づけ、 README.md への明記を求めている。責務の定義自体は単独稼働期から変わっていない。

管理役割主な責務
プロダクトオーナー (PO) 機能の優先順位付け、完了検証、バックログ管理、評価者との窓口
プロジェクトマネージャー / スクラムマスター 進捗・期限の追跡、ブロッカー管理、定例の調整
テクニカルリード / アーキテクト アーキテクチャと技術決定、重要変更のレビュー（sim / WS プロトコル境界）
開発者（全員） 実装・コードレビュー・自分の実装のテスト・文書化

03 — Lanes: retired as an org structure

レーン別の人員配置は、もう管理しない

2026-08-30、レーン別の稼働状況表はこのページから削除した。 旧版の§03「各レーンの稼働状況」は、samatsumが全レーンを兼務している状態を前提にした表で、 チーム運用が始まった今は実態に合わない。レーン（lane:engine / lane:backend / lane:infra / lane:frontend / lane:gameview）はIssueに貼るラベルとしてのみ残っており、 「誰がどのレーンにいるか」を固定的に管理する仕組みではなくなった。

レーンの定義・ラベルの意味・Issue番号との関係は Git運用フロー §05が正本。 GitHub Projectsもレーンごとに分かれていたものを単一の"all" Projectへ統合済みで、 誰が何をやっているかはそちら（Issueのアサイン・ラベル・Projectのボード）を見るのが最新。 このページでは追跡しない。
